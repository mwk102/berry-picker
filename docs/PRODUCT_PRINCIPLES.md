# Product Principles

Every feature should support one or more of these goals.

## 1. Help users decide quickly.

The best interface answers important questions before users need to click.

## 2. Build trust.

Always show when information was last updated and where it came from.

## 3. Reduce planning time.

Users should be able to plan a trip in under 30 seconds.

## 4. Put families first.

Highlight the details families care about:
- restrooms
- parking
- accessibility
- kid-friendly activities

## 5. Keep it simple.

If a feature doesn't help someone discover, decide, or enjoy a farm visit, it belongs in the backlog—not the MVP.

## 6. Design for growth.

Support berries today, but build a platform that can naturally expand to orchards, flower fields, pumpkin patches, and other seasonal experiences.
