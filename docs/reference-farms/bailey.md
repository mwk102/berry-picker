# Bailey Farm Reference Profile

## Why This Farm Is a Reference Farm

Bailey Farm is a Pick-Your-Own produce farm in Snohomish, WA with official current updates that include hours, prices, and available crops. It is useful for testing a mixed produce farm where berry data and vegetable availability need to coexist without overfitting the product to berries only.
